# Lab-Exercise---2---Playfair-Cipher
## Aim :
To implement a program to encrypt a plain text and decrypt a cipher text using play fair Cipher substitution technique. 

## Procedure :
1. Start the program and enter the message to be encrypted.
2. Enter the keyword for the Playfair cipher.
3. Create a 5 × 5 key table using the keyword, removing duplicate letters and combining I and J.
4. Divide the message into pairs of letters, inserting X where necessary.
5. Apply the Playfair cipher rules to encrypt the letter pairs using the key table.
6. Display the final encrypted message.
